## 🚀 Key Features

- **Multi-label Classification** — detects 14 diseases simultaneously from a single X-ray
- **Focal Loss** — handles severe class imbalance (Hernia: 13 samples vs Infiltration: 967)
- **Grad-CAM Explainability** — shows exactly which regions the model uses for each prediction
- **LLM Clinical Reports** — Llama-3 generates professional radiology-style reports
- **Live Demo** — fully deployed and accessible to anyone

## 📊 Dataset

The NIH ChestX-ray14 dataset contains:
- 112,120 frontal-view X-ray images
- 30,805 unique patients
- 14 disease labels extracted via NLP from radiology reports
- Labels accuracy >90%
